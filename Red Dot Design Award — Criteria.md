## Red Dot Design Award — Criteria untuk Software (Desktop & Mobile)

### Referensi Kompetisi

Red Dot Design Award

---

# 1. Struktur Penilaian Resmi

Red Dot mengevaluasi desain berdasarkan empat pilar utama:

* **Function Quality**
* **Usability**
* **Aesthetics**
* **Responsibility**

Untuk software, keempatnya diterjemahkan ke dalam kualitas sistem digital, bukan sekadar visual.

---

# 2. Function Quality (Kualitas Fungsi)

### Definisi

Seberapa efektif produk menyelesaikan masalah utama user.

### Kriteria Teknis

* Problem statement jelas dan spesifik
* Core feature langsung terlihat tanpa eksplorasi panjang
* Workflow efisien (minimal steps)
* Tidak ada fitur yang tidak relevan (feature discipline)
* Performance mendukung fungsi (tidak lag, tidak delay)

### Indikator Lolos

* User bisa menyelesaikan task utama dalam sekali coba
* Tidak perlu dokumentasi untuk memahami fungsi dasar

### Indikator Gagal

* Feature overload
* Value proposition tidak jelas
* UI tidak mencerminkan fungsi utama

---

# 3. Usability (Kemudahan Penggunaan)

### Definisi

Seberapa mudah produk digunakan tanpa instruksi.

### Kriteria Teknis

* Navigation predictable
* Interaction consistent
* Feedback system jelas (state, error, success)
* Learnability tinggi (zero learning curve untuk basic use)
* Input/output behavior intuitif

### Detail Penting

* Desktop: keyboard shortcuts, efficiency
* Mobile: gesture clarity, thumb reach optimization

### Indikator Lolos

* First-time user langsung bisa pakai
* Tidak ada friction dalam flow utama

### Indikator Gagal

* User harus berpikir untuk navigasi
* Hidden interaction tanpa affordance

---

# 4. Aesthetics (Kualitas Visual)

### Definisi

Visual sebagai alat komunikasi, bukan dekorasi.

### Kriteria Teknis

* Typography hierarchy jelas
* Spacing konsisten dan intentional
* Color digunakan untuk makna (bukan estetika semata)
* Visual system scalable (design system)

### Prinsip Utama

* Clarity over decoration
* Minimalism with purpose

### Indikator Lolos

* Informasi terbaca dalam satu glance
* Tidak ada elemen visual yang tidak punya fungsi

### Indikator Gagal

* Overdesign
* Trend-driven UI tanpa fungsi
* Visual noise

---

# 5. Responsibility (Tanggung Jawab Desain)

### Definisi

Dampak jangka panjang terhadap user dan sistem.

### Kriteria Teknis

* Performance ringan dan efisien
* Accessibility (contrast, screen reader, inclusive design)
* Tidak menciptakan dependency negatif (dark patterns)
* Longevity (tidak bergantung tren visual sementara)

### Indikator Lolos

* Produk tetap usable dalam jangka panjang
* Bisa digunakan oleh berbagai tipe user

### Indikator Gagal

* Heavy resource usage
* Accessibility diabaikan
* UX manipulatif

---

# 6. Kriteria Tambahan (Implisit untuk Software)

## Interaction Quality

* Transisi halus dan bermakna
* Tidak ada animasi yang mengganggu fungsi

## System Consistency

* Pattern reusable
* Tidak ada inkonsistensi antar screen

## Technical Execution

* Stability (tidak crash)
* Responsiveness cepat
* Cross-platform consistency (desktop & mobile)

---

# 7. Framework Evaluasi Internal (Checklist)

Gunakan ini sebelum submit:

### Core

* Apakah satu fungsi utama benar-benar dominan?
* Apakah user bisa langsung mengerti tanpa onboarding?

### UX

* Apakah semua interaction predictable?
* Apakah flow utama bebas friction?

### UI

* Apakah setiap elemen punya fungsi jelas?
* Apakah visual membantu keputusan user?

### System

* Apakah performa stabil di semua kondisi?
* Apakah scalable untuk masa depan?

---

# 8. Prinsip Kunci untuk Menang

* Fokus pada **clarity**, bukan kompleksitas
* Eliminasi semua yang tidak esensial
* Jadikan UI sebagai representasi langsung dari fungsi
* Pastikan pengalaman terasa “natural”, bukan “designed”

---

# 9. Posisi Ideal Submission

Untuk software seperti yang kamu bangun:

* Kategori: Communication Design
* Fokus utama:

  * Interface clarity
  * Workflow efficiency
  * Interaction simplicity

---

# 10. Ringkasan Strategis

Red Dot tidak mencari:

* UI paling keren
* teknologi paling kompleks

Red Dot memilih:

* produk yang paling jelas
* paling mudah digunakan
* paling konsisten secara sistem
